🚀 Getting Started

Welcome to the Physics Viewer! This tool helps you browse, filter, and export physics question papers with ease.

Login

When you first open the page, you'll see a login screen:

  • Enter your password in the text field
  • Press Enter or click the Login button
  • Your session is saved - you won't need to re-enter the password on subsequent visits
  • If you get locked out, clear your browser cache and try again
💡 Tip: After logging in, you'll see the main interface with a table of all available papers and a PDF viewer above.

🔍 Filters

Use the dropdown filters to narrow down the papers you want to see. Each filter allows multiple selections.

📅

Year Filter

Filter papers by year. Select one or multiple years to see papers from those years only.

📄

Paper Filter

Filter by paper type (e.g., P1, P2, P3). Select multiple paper codes.

❓

Question Filter

Filter by question number (e.g., q1, q2, q3). Useful for finding specific questions.

📂

Topic Filter

Filter by main topic. You can also enable "Other Topics" to include papers that have the selected topic as a secondary topic.

How to Use Filters

  1. Click on a filter button (e.g., Year)
  2. Check the boxes for the items you want to include
  3. Click Apply to filter the table
  4. The count on the button shows how many items are selected
  5. To clear a filter, uncheck all items and click Apply
💡 Tip: You can combine multiple filters at once (e.g., Year + Topic + Level) to narrow down results precisely.

🎯 MCQ Levels

The system automatically detects MCQ questions and assigns difficulty levels based on a separate MCQ.json file.

Level Definitions

L1

Level 1 - Recall

Basic recall of facts, definitions, and simple concepts.

L2

Level 2 - Comprehension

Understanding and interpreting information.

L3

Level 3 - Application

Applying knowledge to new situations.

L4

Level 4 - Analysis

Breaking down complex problems and analyzing components.

L5

Level 5 - Mastery/Synthesis

Combining concepts and solving complex, multi-step problems.

Using the Level Filter

  • Click the Level filter button
  • Check one or more levels (e.g., L1, L2, L3)
  • Click Apply to show only questions at those levels
  • Only files with assigned levels will appear when filtering

Visual Indicators

  • 📌 Color-coded badges appear next to filenames for MCQ questions
  • Level 1 - Green
  • Level 2 - Blue
  • Level 3 - Orange
  • Level 4 - Red
  • Level 5 - Purple
  • 💡 Row background colors also match the level for quick visual scanning
  • Non-MCQ questions show no badge and have a standard row color
⚠️ Note: MCQ levels are loaded in the background. If you don't see levels immediately, wait a few seconds. The app will show a toast notification when levels are loaded.

📊 Table Features

☑️

Row Selection Checkboxes

Each row has a checkbox. Use the "Select All" checkbox in the header to toggle all rows. Uncheck individual rows to exclude them from exports.

🔽

Sortable Columns

Click any column header to sort by that column. Click again to reverse the sort order (ascending/descending).

🖱️

Click to View PDF

Click on any row to load the corresponding PDF in the viewer above. The viewer will display the full paper.

📈

File Counter

The top-right shows how many files are currently displayed in the table. If more than 500 files, it shows "Top 500/X" to indicate the display limit.

Display Limit

For performance reasons, the table only displays the first 500 files. However:

  • ✅ All filters apply to the full dataset (not just the 500 displayed)
  • ✅ Exports (HTML, PDFs, ZIP) include all filtered files (not just the 500 displayed)
  • ✅ The file counter shows the total filtered count

📦 Export Tools

All export tools are located in the ⬇️ dropdown menu next to the MS toggle.

📄

HTML Report

Generates an HTML page with embedded PDFs of all selected files. Great for offline viewing or sharing with students.

⚠️ Limit: 100 files recommended for browser stability.

📑

PDF Merge

Merges all selected PDFs into a single PDF file. Each file starts with a banner page showing the filename.

⚠️ Limit: 50 files recommended for memory stability.

📦

ZIP Download

Downloads all selected PDFs as a ZIP file. The original filenames are preserved.

⚠️ Limit: 100 files recommended for browser stability.

How Exports Work

  1. Select files using the checkboxes (all are selected by default)
  2. Uncheck any files you don't want to include
  3. Click the ⬇️ dropdown to open the tools menu
  4. Choose HTML, PDFs, or ZIP
  5. Only the checked files will be processed
  6. The file will download automatically
💡 Tip: Use the checkboxes to create custom selections. For example, select only Level 4 and Level 5 questions, or only questions from a specific year, then export them.

📝 Mark Schemes (MS)

The app automatically detects mark scheme files if they follow the naming convention.

How It Works

  • Toggle the MS switch to enable mark scheme viewing
  • When you click a row, the app will try to load filename_ms.pdf in the same folder
  • If found, the mark scheme appears side-by-side with the question paper
  • If not found, you'll see a notification that the mark scheme isn't available
📌 Important: Mark schemes are not automatically included in exports. The MS toggle only affects the viewer display.

🧭 Navigation

The Goto dropdown in the top-right corner lets you switch between different paper collections:

  • 9702 - Cambridge A-Level Physics papers
  • SEAB - Singapore SEAB papers
  • Prelim - Preliminary exam papers
  • Data - Additional data resources

⌨️ Keyboard Shortcuts

  • Ctrl+Shift+D - Toggle the Debug Console
  • Enter - Submit login password

🔧 Troubleshooting

🔄

Login Not Working

Clear your browser cache and try again. The session might have expired.

📂

No Levels Showing

MCQ.json loads in the background. Wait a few seconds. Check the debug console (Ctrl+Shift+D) to see if it loaded.

📄

PDF Not Loading

Make sure the PDF exists in the folder. The app tries to load from /pdfs/<year>/<filename>.

💾

Export Fails

Too many files selected? Try reducing the selection. The app has limits to prevent browser crashes.
